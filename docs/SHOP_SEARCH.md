# 商城筛选与搜索

商城排序栏点击「筛选」，可组合现货／预售、有货／售罄和价格区间，与分类、关键词、排序共同生效。编辑后点击「确定筛选」查询；取消不改变已应用条件，重置后须确定才生效。价格按最低在售规格价筛选，单位为元、最多两位小数，边界包含，留空不限；无在售规格商品不参与价格筛选。有货要求至少一个在售规格库存和每单限购都大于零。全部条件在服务端分页前应用，演示模式规则相同。

点击搜索框展开搜索历史与推荐搜索词。确认搜索或点击历史／热门词时记录历史，输入防抖过程不记录。历史最多10条，重复搜索置顶，可逐项删除或确认清空；仅保存在当前设备，演示和正式模式隔离，不跨设备同步。

推荐搜索词取销量排序前6款已上架商品的名称，去重后展示，文案明确注明「按在售商品销量推荐」。这是销量推荐词，不是搜索次数排行榜。点击词条保留已应用的分类、筛选及排序；无法加载可重试，没有商品时显示空状态。

商城「组合筛选收藏」可保存当前关键词、分类、排序、发货方式、库存状态和价格区间，点击收藏项一键恢复全部条件并从第一页查询；筛选面板未确定的草稿不会被保存。组合以条件自动命名，相同组合再次收藏置顶，价格等值写法合并；最多10组，达到上限提示先删除，支持逐项删除。仅保存在当前设备，演示和正式模式隔离，不跨设备同步。空收藏有提示，存储失败保留原列表并提示，不会影响商品查询。损坏的本地记录读取时跳过。

推荐搜索词在打开搜索面板时刷新，点击后保留当前分类、筛选及排序。推荐来源沿用在售商品销量，无需运营配置或新增后端接口。

正式上线同步发布后端 `product.search` 和小程序，无需数据库迁移。接口新增 `saleMode`（all/spot/presale）、`stock`（all/available/soldOut）、可选 `minPrice` / `maxPrice`（整数分，0至100000000）；旧调用无需传新字段。

验证：`npm run test:shop`、后端 `go test -run 'TestProduct(Search|Page)' ./...`。发布前需生成小程序 JavaScript，并在微信开发者工具检查真机输入、按钮点击及布局。

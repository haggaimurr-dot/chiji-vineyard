# 批次外部溯源与二维码

后台「商品管理 → 批次管理」新增或编辑批次，点击「关联平台」，填写平台名称、该批次的 HTTPS 查询链接及可选平台编码。保存后，小程序「批次溯源查询」会展示平台资料，买家可复制链接在浏览器打开。移除平台关联后保存即可取消展示。链接必须是公开查询地址，不能包含账号密码。

批次列表点击「生成二维码」，可预览并下载 640×640 PNG：

- 内部溯源码：内容为系统批次 ID。在小程序「批次溯源查询」点击「扫描溯源码」即可查询；普通扫一扫不会自动打开小程序。
- 外部平台链接：内容为所保存的 HTTPS 查询地址，可用微信扫一扫或浏览器扫码访问平台。访问效果由平台及微信的域名策略决定。

二维码在后台本地生成，不上传到第三方二维码服务。归档批次仍支持查询历史资料。订单保存的批次快照包含当时的外部平台关联，之后编辑批次不会改写快照；公开溯源查询读取最新批次档案，不公开内部备注或订单信息。

本次提供外部平台的链接接入，不调用供应商 API，不自动注册溯源码或同步检验数据。接入特定平台 API 需另行提供其接口协议和服务端凭证。新增字段保存在现有批次 JSON 中，无需数据库迁移。

验证：`npm run test:batches`、`npm run check`，以及在 `backend/` 执行 `go test ./...`。上线前使用实际平台地址检查扫码、浏览器访问和小程序真机查询。

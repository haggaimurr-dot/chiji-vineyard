# 订单进度与物流异常提醒

运营后台订单列表通过“订单进度”查看所有状态的订单，原“快递轨迹”入口也打开进度抽屉。小程序订单详情直接展示时间线和异常提醒。

时间线包含提交、付款、发货、承运商轨迹、确认收货、完成、取消/关闭和当前售后状态。轨迹按时间正序排列。未保存的历史时间显示“时间未记录”，未来步骤显示“待完成”。演示物流节点明确标注。

提醒依据快递100返回的状态：运输异常（2）、退签（4）、退回（6）；成功查询的轨迹超过48小时未更新，以及发货超过24小时仍未获得轨迹，也会提醒核实。无查询权限、服务未配置或演示模式不会生成超时提醒。已签收不再提醒轨迹停滞，已确认收货或终止订单不再显示物流异常。查询失败且有历史数据时，保留历史异常状态并提示当前轨迹来自上次查询。

提醒在查询物流时更新，沿用30分钟缓存；目前为页面内提醒，不主动发送微信订阅消息、短信或后台定时推送。物流服务仍需配置 `KUAIDI100_CUSTOMER` 和 `KUAIDI100_KEY`。

验证：`node tests/order-progress.cjs`、`npm run check`、后端 `go test ./...`。

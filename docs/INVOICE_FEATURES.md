# 发票下载与自动邮件通知

用户在订单详情申请电子普通发票，填写个人或企业抬头、税号（企业必填）及接收邮箱。运营人员在后台订单中选择「待开票」，核对资料后填写发票号码、上传 PDF（最大3MB），点击「保存并发送邮件」。保存开票结果后，系统自动向申请邮箱发送包含 PDF 附件的通知。

已开票订单在小程序提供「下载发票」按钮，打开 PDF 后通过右上角菜单保存或转发。下载文件在查看器打开后保留，供菜单使用；再次下载覆盖同一个本地文件，避免不断占用存储空间。后台订单也可直接下载原始 PDF。文件通过已登录接口读取，不暴露公共下载地址。

后台展示邮件状态：等待发送、正在发送、邮件服务已接受、发送失败或发送结果待核实。明确失败时可点击「重试发送」；已成功发送不会重复发送。不确定结果须先检查邮件服务记录，再登记「核实已发送」或「核实未发送」，核实未发送后方可重试。SMTP 接受邮件不代表用户收件箱已收到，用户可检查垃圾邮件或直接下载。

正式环境需执行 `backend/schema.sql` 中 `invoice_requests` 和 `invoice_files` 的建表语句，并在后端配置 `.env.example` 中的 `SMTP_HOST`、`SMTP_PORT`、`SMTP_TLS_MODE`、`SMTP_USERNAME`、`SMTP_PASSWORD` 和 `SMTP_FROM`。465 端口使用 `tls`，587 使用 `starttls`；密码填写邮箱服务要求的授权码。未配置时仍保存发票，邮件标记失败，完成配置后可重试。

演示后台只模拟邮件发送，与小程序演示数据独立。本地功能检查运行 `npm run test:invoices`；真实 SMTP 收信及微信 PDF 保存、转发需在配置服务后验收。

新增自动开票与售后工单说明见 [AUTO_INVOICE_AND_TICKETS.md](AUTO_INVOICE_AND_TICKETS.md)。

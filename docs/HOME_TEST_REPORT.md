# 首页模块完善与 mock 验收

验收日期：2026-10-05（北京时间）。按本次要求继续使用 mock 数据。

## 素材与操作

- 小程序演示首页使用两张本地葡萄示意图作为轮播；后台演示首页及三款商品使用对应图片，不依赖外部图片服务。图片沿用仓库已有生成素材，页面保留示意标识。
- 后台「运营配置 → 首页运营位」支持直接上传 JPG / PNG / WebP，单张不超过 4MB。上传仅修改当前编辑，需点击「保存并预览首页」发布配置；上传期间锁定表单，错误格式、超大文件和上传失败保留原图片。
- 小程序首页为轮播、商品与文章图片提供失败提示；再次读取配置时重置图片失败状态，旧图片或旧请求的错误事件不能隐藏新素材。商品起价使用最低规格价，与商城一致。
- 后台演示上传保存为本地 data URL；正式接口仍只接受 HTTPS 轮播地址。演示后台和演示小程序独立，后台保存不会直接同步到演示小程序。

## 已通过的检查

| 检查 | 结果与范围 |
| --- | --- |
| `npm run check`、`npm run mini:build` | 两端类型检查、后台构建、小程序 JS 输出 |
| `npm run test:operations` | mock 后台保存经模拟云传输进入实际小程序逻辑：轮播图片替换、介绍与合作文案、推荐顺序、模块删除、未来公告隐藏、跨年月筛选、下架目标、错误恢复、过期响应及图片错误隔离 |
| `npm run test:config-history` | 保存版本、回滚、权限与会话持久化 |
| `npm run test:flows` | 首页、商品、隐私及现有订单流程回归；缺少主体的政策用例显式清空主体后验证 |
| `go test ./...`（backend） | 包含真实 HTTP 路由的保存 / 回读 / 用户端读取；数据库使用测试驱动 |
| `npm run test:home-ui` | 浏览器实际操作：mock 图片加载、上传、错误格式与超大文件、保存回读、新图预览、刷新持久化、坏链接、1360 / 1024 宽度无水平溢出；无页面 JS 异常 |

浏览器检查需先运行 `npm --workspace admin run dev -- --host 127.0.0.1 --port 5181 --strictPort`，脚本默认使用已安装的 Edge。可用 `ADMIN_UI_URL`、`PLAYWRIGHT_BROWSER` 指定地址和浏览器。

截图与浏览器结果在 `tests/artifacts/home-ui-*.png`、`tests/artifacts/home-ui-results.json`。已查看初始 mock 预览和较窄窗口图片失败状态截图。

## 跨端验证边界

本次验证的是 mock 保存与模拟传输，以及后端测试驱动下的接口读写。未连接真实 MySQL、云托管或微信真机。正式跨端更新需两端指向同一服务，保存后再次进入首页或下拉刷新读取，不是后台保存后实时推送；操作步骤见 [跨端验收](CROSS_END_ACCEPTANCE.md)。

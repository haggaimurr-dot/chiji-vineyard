配置版本、回滚及操作日志的保存、快照、原因确认、并发冲突、权限、北京时间查询与数据库事务验收见 [配置历史说明](CONFIG_HISTORY.md)。本地执行 `npm run test:config-history`，并在验收数据库核对真实锁竞争与日志/版本/配置一起提交。

保存预览、跨端配置更新与账号密码重置的操作、异常场景及记录模板见 [专项验收](CROSS_END_ACCEPTANCE.md)。本地模拟检查与真实 MySQL / 微信联调需分别记录。

批量发货、订单导出、快递100真实电子面单的逐单结果、并发幂等、超时待核实及打印验收见 [订单运营操作手册](ORDER_OPERATIONS.md)。本地测试通过后，仍须使用已开通的真实网点/月结账号验证取号与打印。

## 商城

- 商品分类、现货/预售、家庭装/礼盒规格、限购和售罄状态正确。
- 服务端忽略客户端价格；同时下单不会超卖；超时、取消会释放库存。
- 运费门槛、禁售地区和订单地址快照正确。
- 重复点击支付、重复支付通知不会重复记账或重复扣库存。

## 履约与售后

- 只有已支付且无退款中的订单可发货。
- 运单同步失败会在后台明确显示，可由运营人员修正后重试。
- 已支付未发货、已发货、已收货订单可申请全部或部分金额退款；同一订单只能存在一条进行中的申请。
- 金额为整数分，拒绝零、负值、超额和累计超额；部分退款后保留履约状态及剩余可退金额，可再次申请。
- 未发货举证可选，已发货/已收货举证必填；最多6张，单张512KB，验证真实JPEG/PNG/WebP类型，失败可重试和删除。
- 举证不可通过公共素材接口访问，用户不能查看其他人的举证或关联其他订单、已使用图片；后台登录后可查看。
- 成功通知重复或乱序不得重复累计金额或回补库存；部分退款不回补，累计退满仅未发货订单回补，已发货退款不回补。
- 确认收货仅适用于已发货订单。

## 内容与合作

- 定时发布、内容版本恢复、多人编辑冲突和阅读统计口径的完整验收见 [内容功能说明](CONTENT_FEATURES.md)。本地运行 `npm run test:content`；正式跨端和多实例验收使用同一后端与真实 MySQL。

- 课堂可按种植阶段和品种组合筛选，草稿不对小程序公开。
- 合作表单校验手机号、必填项和隐私同意；五分钟内同手机号重复提交不产生重复线索。
- 后台可更新线索状态、跟进备注并导出带 UTF-8 BOM 的 CSV。
- 合作线索支持客户、联系人、手机、采购需求、负责人及历史备注搜索，空格分隔多个词；状态、渠道、地区、负责人、提醒状态可组合筛选，筛选先于分页，切换条件回到第一页。验证空结果、异常重试、快速切换条件、每页条数和上一页/下一页。
- 验证负责人分配、取消分配和启用账号校验，连续跟进及旧备注历史保留，提醒设置、完成、移除、重新安排，以及成交 / 关闭后结束提醒。验证顶部全部 / 我的提醒、到期数量和跨页面定位。两页面并发保存应提示冲突、刷新最新状态并保留草稿；演示刷新后仍保留线索与历史。详见 [线索专项验收](LEAD_WORKFLOW_TEST_REPORT.md)。
- 连续追加两次跟进，旧备注不被覆盖；仅改变状态时最近备注保留，历史包含状态变化、操作人和时间。旧备注转为时间未知的历史记录；取消不保存，空白且状态未变时不可保存，失败保留输入。正式模式并发追加不得丢失记录，演示模式刷新仍保留历史。
- CSV 导出当前已应用条件下的全部匹配线索，跨页完整，包含最近备注和全部历史；验证中文、逗号、引号、换行及公式开头文本。
- 本地线索流程检查：`npm run test:leads`。正式数据库锁和并发更新仍需在部署环境验收。

## 安全与上线

- 小程序端不能直接读写数据库，后台接口拒绝无效或过期管理员令牌。
- 运营人员不能修改仅超级管理员可变更的系统配置。
- 支付证书、API v3 密钥、AppSecret 不出现在前端包、日志或 Git 中。
- 演示支付在生产环境关闭，支付/退款回调均完成验签和五分钟时间窗检查。



## 本次补齐功能

- 保存轮播位标题、图片、按钮及跳转目标，小程序重新显示首页后同步变化；轮播顺序和推荐列表顺序一致，草稿目标不能保存，下架内容不展示。
- 库存批量选择、零库存、取消选择正常；一次调整多个 SKU 成功后刷新数值。打开批量表单后产生新订单，再提交旧库存预期，应整批失败且所有库存保持该次提交前的值；审计记录包含调整前后值和原因。
- 未发货订单没有轨迹入口；用户不能查询其他人的订单。已发货订单可查询、刷新、复制运单号；后台可查看同一轨迹。半小时内复用缓存，供应商失败保留上次已有节点，不制造签收事件。
- 政策草稿可保存，缺少主体/联系方式/地址不能发布；正式模式不展示草稿，发布后“我的”、收货地址、结算和合作表单可阅读完整十节正文并复制联系信息。演示政策须显示预览标识。
- 本地验证：`npm run check`、`npm run test:flows`、在 backend 执行 `go test ./...` 与 `go vet ./...`。真实数据库事务、微信小程序界面、供应商实单和平台隐私授权需部署环境验收。

地址验收：旧单地址保留为默认地址；新增多个地址，编辑不覆盖其他地址；设为默认后只有一条默认；删除默认地址后自动补选，删除最后一条后列表为空；结算默认带入默认地址，手动选址不修改默认设置，所选地址编辑或删除后结算同步刷新；微信导入经授权后填入表单，保存前不写入列表，取消或拒绝授权可继续手动填写；地址修改不影响历史订单快照。

## 优惠券、配送日期与发票申请

- 演示结算使用 DEMO10，商品满99元减10元；无效码、未达门槛不得提交支付。取消券后恢复金额。
- 正式模式后台新建券，验证未生效、过期、停用、门槛、每用户限一次；同时创建两个不同SKU订单使用同码，只允许一单成功。取消/关单释放，支付后退款不返券。
- 切换地址/优惠券快速触发报价，较早响应不能覆盖最新金额；报价失败或未返回时不能支付。
- 配送选期望日期或尽快配送；拒绝过去、两天内、超过30天或早于预售发货日期，订单详情与后台显示一致。
- 未支付或退款中的订单不能申请发票；个人抬头不要求税号，企业要求税号，邮箱和抬头必填。同单重复提交拒绝；按实付金额申请。
- 后台查看申请资料；人工开具并发送至邮箱后登记号码，拒绝时填原因。已退回可重提；已开票不得重复处理。开票前退款状态改变时拒绝登记。
- 上线前执行新增数据库初始化语句，并用真实MySQL验证锁、并发及状态流程；单元测试和演示流程不能代替线上开票或支付验收。

## 再次购买、订单搜索、发货通知

- 在订单列表和详情再次购买：当前价格显示正确；购物袋中同规格的其他数量不覆盖本次购买；下架、已删除规格、售罄、库存或限购减少均有提示；取消变化确认不跳转。
- 搜索订单号、商品名称和规格；空格分隔多关键词；与状态切换联动；超过一页的数据仍能搜索到；空结果、异常重试、分页和快速切换搜索正确。用户不能搜索到其他用户订单；后台搜索不影响退款列表。
- 发货后「我的」出现未读通知，打开对应订单后已读；退出再进入保持已读；重试微信物流同步不产生第二条通知。
- 真机配置实际模板后，分别验证用户同意、拒绝、取消授权及微信禁用订阅；授权与发货同时发生；成功推送跳转正确订单。明确错误允许重试；网络结果未知时保持待核实且不自动重复发送。未配置模板仍能查看站内通知。
- 演示发货和订阅仅保存本地状态，不发送真实微信消息；正式后端不提供模拟发货接口。

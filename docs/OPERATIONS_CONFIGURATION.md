# 分地区运费模板与活动管理

运营后台 → 运营配置，通过顶部快捷入口进入两个管理区域。仅超级管理员可保存运营配置。

## 分地区运费模板

- 未匹配地区使用默认运费，区县模板优先于城市、城市优先于省份；禁售省份始终生效。
- 最多100条模板，可新增、编辑、复制和删除。复制保留计费参数，清空省市区，需填写新地区后保存；同一地区不能重复配置。
- 支持基础运费、基础件数、续件费、包邮门槛、地区附加费、区域暂停配送和暂停配送日期。包邮仍收取地区附加费。
- 运费试算使用当前编辑内容，填写地区、商品金额、件数及配送日期即可查看匹配模板与运费。保存后才影响实际结算。
- 保存使用既有运费配置接口，记录在“运费规则”版本历史中，可回滚。

## 活动管理

- 最多12条活动，可新增、编辑、上移、下移和删除；支持标题、简介、详情、开始/结束日期、关联商品及预约开关。
- 关联商品可留空；有商品关联时应选择已发布商品。预约活动标识在编辑、排序和保存时保持稳定。
- “预览活动”查看当前编辑，“保存活动与首页”同时提交活动和首页当前编辑，成功后回读并打开保存值预览。
- 活动保存记录在“首页运营位”版本历史中。回滚首页配置会同步恢复活动，丢弃旧草稿。
- 活动与首页共用一份编辑数据，避免多个活动编辑入口相互覆盖。日期规则沿用现有北京时间规则。

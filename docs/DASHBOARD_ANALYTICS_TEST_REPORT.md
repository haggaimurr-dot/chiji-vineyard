# 经营概览访问与加购验收

验证日期：2026-10-08。本地演示环境；未连接生产 MySQL、未执行生产迁移或发布。

- 新增访问 → 加购 → 下单 → 支付 → 收货人数漏斗，原订单漏斗保持按单统计。
- 前台访问触发采集；同日重复访问、加购保留首次记录。成功商品页加购由服务端记录；数量编辑、勾选、删除不记录加购。
- 日期边界、用户去重、直接购买排除、加购前订单排除、曾付款的退款订单、空数据、历史覆盖提示均通过测试。
- 首次进入时访问上报与页面请求共用一次登录；已注销账号不自动上报。删除使用记录和注销纳入采集记录清理。
- 统计查询保持同一只读事务快照，访问统计失败回滚并由页面显示可重试错误。

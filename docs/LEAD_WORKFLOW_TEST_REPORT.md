# 合作线索负责人、跟进历史与提醒验收

验收日期：2026-10-05（北京时间）。本报告覆盖本地演示和服务端自动测试。

## 检查清单

| 需求 / 控件 | 功能检查 | 可视检查与证据 |
| --- | --- | --- |
| 分配、变更和取消负责人 | 只可选择启用账号；更新不覆盖其他字段；负责人筛选 | 线索表负责人、编辑表单和分配历史 |
| 新增跟进及跟进历史 | 连续新增备注、重复备注、状态变更；旧备注保留；刷新持久化 | 历史时间线、操作人、时间和变更标签 |
| 设置、移除、完成与重新开启提醒 | 本地时间转换；未来时间校验；关闭线索结束提醒 | 表格到期状态、提醒编辑器、完成状态 |
| 全局提醒 | 全部 / 我的范围；点击定位；刷新、Escape、页面切换 | 顶部数量、提醒面板与对应线索抽屉 |
| 搜索、筛选、分页、CSV | 保留渠道、地区和历史搜索；新增负责人 / 提醒筛选；导出全筛选结果 | 筛选空状态、表格及分页 |
| 并发和失败 | 版本冲突保留草稿；事务失败无部分修改；错误有重试入口 | 冲突提示、加载 / 历史错误提示 |
| 视口与长内容 | 桌面 1600×1000 和最小支持宽度 1180；长备注和密集历史 | 表格、提醒面板及抽屉无遮挡、控件可操作 |

补充探索：从经营概览打开提醒对应线索；相同备注连续提交；将编辑状态改为成交；没有匹配线索时重置筛选；过期提醒重开被拒绝并保留表单。

## 验收结果

- `npm run check`：通过小程序与后台 TypeScript 检查、后台生产构建。
- `npm run test:leads`：通过搜索和分页、负责人校验、身份记录、提醒生命周期、版本冲突、旧数据迁移、持久化和存储失败保护。
- `go test ./...`：后端全部测试通过，包括线索 / 历史 / 审计事务回滚、并发更新、停用负责人、公共提交字段隔离及超过500条提醒的查询。
- `go build ./...`：通过。
- 浏览器通过真实控件验证：分配和取消分配负责人；状态与备注保存；重复备注生成新历史；旧备注保留；刷新后保留负责人、备注和提醒；到期提醒完成；过期提醒重开被拒绝；未来时间重新安排；移除提醒；成交自动完成原提醒。
- 两个页面同时编辑同一线索：后保存的页面提示版本冲突，保留已输入备注，合并未编辑的最新状态；核对后再次保存成功。
- 顶部提醒的全部 / 我的切换、刷新、Escape 关闭和从经营概览定位线索通过；负责人、状态、渠道、地区和提醒筛选、空结果重置、历史备注组合搜索、每页条数切换及筛选 CSV 导出通过。分页边界由自动测试补充验证；本次界面导出验证为筛选后的单页数据。
- 演示存储损坏时显示错误，未覆盖原数据；恢复原数据并点击刷新后，全部已保存内容恢复。
- 1600×1000、1180×900 视口检查通过。1180px 时文档宽度1180px，表格可视宽度及内容宽度均为856px，跟进按钮右边界1124px。表格、提醒面板与抽屉的主要控件没有水平溢出或遮挡；密集历史在抽屉内滚动，底部保存控件始终可见。最终操作期间没有页面运行异常。

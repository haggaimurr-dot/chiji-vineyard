## 修复及限制

- 首次打开模拟器提示 `pages/home/index.js` 不存在。本机未自动生成 TypeScript 对应的 JavaScript。新增 `npm run mini:build`，生成相邻 JS，修复模拟器启动；生成文件已加入 Git 忽略规则，README 补充操作步骤。
- “我的”政策入口改为“隐私政策”，与当前实际页面内容一致。
- 本机开发者工具出现页面路由完成超时、部分自动化元素/截图接口无响应。等待切换完成后完成上述功能检查；快速连续切页仍需复查，不能将这次功能检查视为模拟器稳定性验收通过。清理了项目编译缓存，临时测试过工具 API hook/热重载设置，结束后已恢复原有私有配置。
- 测试发货由注入明确标识的演示运单完成，未调用真实商家发货、微信支付或快递100实单接口。测试用的订单、购物车、地址和结算存储已恢复。
- 首页后台保存与跨端更新、批量库存调整是后台/后端功能，不在微信模拟器中直接操作；此前本地流程与 Go 事务测试已通过，本次没有完成跨端正式数据库联调。

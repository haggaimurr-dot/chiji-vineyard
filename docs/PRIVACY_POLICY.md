# 迟记葡萄牙隐私政策

版本：1.1；拟生效日期：2026-10-03。

发布前在后台填写营业执照主体全称、隐私联系渠道及联系地址，核实实际供应商、保存期限及安全措施，再发布。本文完整正文同步于 backend/privacy.json，尚未发布。

一、适用范围与运营主体
本政策适用于“迟记葡萄牙”小程序的商品浏览、购物车、下单配送、支付退款、种植课堂及合作咨询服务。运营主体、联系地址和隐私事务联系方式见本页顶部。微信平台及第三方独立提供的服务适用其各自的隐私规则。本政策不代替微信小程序平台的隐私保护指引。

二、我们处理的信息、目的与处理方式
1. 微信登录：我们通过微信登录获取登录凭证，并由服务器向微信换取 OpenID，用于识别账号、关联购物车、地址和订单，验证访问权限；不主动读取微信头像、昵称、通讯录或聊天记录。
2. 购物与配送：您填写的收货人姓名、手机号码、省市区和详细地址，用于订单履约、配送联系及售后处理。地址可由您主动填写，也可在您点击“从微信导入地址”并授权后读取微信中由您选择的收货人姓名、手机号码和收货地址；导入后由您核对并保存。
3. 订单与支付：我们处理商品规格、数量、金额、订单号、备注、支付状态、微信支付交易号、退款理由、申请金额、举证图片及退款状态，用于核算、发货、退款和争议处理。支付由微信支付完成，我们不收集银行卡号、支付密码。优惠券兑换码、抵扣记录及您选择的期望配送日期用于核算和配送安排；申请发票时，您填写的抬头类型、发票抬头、企业税号和接收邮箱，以及申请状态、发票金额和号码，用于商家审核、开具并发送发票，不申请发票无需提供这些信息。请勿在备注或退款说明中填写身份证号、健康信息等与服务无关的信息。
4. 物流：我们处理承运商、运单号、发货时间、物流节点和收货状态，用于查询配送进度。查询服务可能需要收货手机尾号核验运单。
5. 合作咨询：您主动提交的企业或个人名称、联系人、手机、地区、渠道、采购量和需求，用于回应咨询及商谈合作。提交合作需求需由您主动勾选联系授权；您可以通过隐私联系渠道撤回。
6. 服务安全：登录状态、访问时间及必要的服务错误信息用于防止非法访问和排查故障。我们不以本服务收集的信息进行广告画像，不主动获取精确位置、相册、麦克风或通讯录。您主动添加售后举证时，可选择拍照或从相册选择图片，仅上传您选择的图片，用于商家核实和争议处理，只有您和授权运营人员可查看。请遮盖无关个人信息。
7. 经营统计：记录登录用户的访问日期、首次访问时间和成功加入购物袋时间，用于按用户去重统计访问、加购及后续下单转化；后台仅展示聚合人数，不展示用户标识。购物袋编辑和直接购买不作为加购记录。您可在个人数据管理中删除使用记录。

三、处理依据与您的选择
我们以履行您订立的订单合同、履行法定义务等适用依据处理必要信息；对于基于同意开展的处理，我们会提供明确说明并由您作出选择。可选信息不填不影响其他服务。不提供收货地址或支付必要信息会使相关订单无法完成；不提交合作联系方式会使我们无法回应合作咨询。我们不会仅因您拒绝可选处理而拒绝无关服务。

四、委托处理及向第三方提供
1. 微信及微信支付提供登录、交易与退款服务，我们向其传递必要的登录凭证、订单号、金额等信息。
2. 腾讯云提供本服务的云托管、数据库与素材存储等基础设施，按约定处理服务数据。
3. 为配送订单，我们向订单使用的承运商提供收货人、联系方式、配送地址及必要的订单配送信息。承运商名称可在订单详情查看。
4. 开通快递查询时，深圳前海百递网络有限公司（快递100）提供物流查询，我们传递承运商编码、运单号和必要的手机尾号，不传递商品详情和完整收货地址。
我们会依实际合作关系确定委托处理或向独立处理者提供的安排，要求服务商在约定范围内处理并采取保护措施；依法需要单独同意时，在提供前另行告知并征求同意。除履约、您授权的情形或法律规定外，我们不向其他组织出售个人信息。不公开披露个人信息；依法必须披露的除外。

五、保存地点与期限
本服务收集的信息存储于中国境内。当前服务不主动向境外提供个人信息；如以后需要，将依法履行告知、评估及相应程序。我们按目的所需的最短期限保存信息，并遵守交易信息等法定保存要求。订单及相关交易记录自交易完成之日起保存不少于三年，法律另有更长要求的依其规定。地址列表在您更新、删除或提出删除申请前用于后续下单；历史订单地址快照作为交易记录按订单期限保存。未达成合作的咨询记录原则上自最后一次联系起保存一年，之后删除或匿名化；转为交易的按交易期限保存。物流查询缓存按服务需要更新，可随订单记录保存。安全日志原则上按服务安全需要保存六个月，法律另有要求或争议处理确有必要时延长。

六、信息安全
我们采取身份认证、角色权限、传输保护及必要的访问审计等措施，仅允许履约和服务所需的人员访问相关信息，并要求其承担保密义务。任何系统都无法保证绝对安全。发生个人信息安全事件时，我们会采取补救措施，按法律要求向主管部门报告，并以适当方式告知受影响用户；采取措施能够有效避免危害的，按适用规定处理。

七、您的权利及行使方式
您可以在“我的—收货地址”查看、新增、修改、删除收货地址及设置默认地址，在“我的—订单”查看订单。您有权依法申请查阅、复制、更正、补充或删除个人信息，撤回基于同意的授权，申请注销本服务账号，或要求解释个人信息处理规则。未设置自助入口的请求，请通过本页隐私联系方式提出，并说明所需操作及相关订单号；我们仅在必要范围内核实您的身份。原则上在十五个工作日内答复，复杂情形会说明进度及理由。撤回同意不影响撤回前已进行处理的效力，也不影响基于其他合法依据进行的必要处理。删除或注销可能影响未完成订单，请先处理正在进行的交易；依法必须保留的记录，将限制为存储及必要的保护用途，期满删除或匿名化。您可通过微信设置管理平台权限，平台权限调整与本服务记录删除是不同操作。对答复不满意的，可以向有管辖权的监管部门投诉或依法寻求救济。

八、未成年人保护
本服务主要面向成年人。不满十四周岁的未成年人应在监护人指导下使用；我们不主动收集其个人信息。若发现未经监护人依法同意处理不满十四周岁未成年人信息，我们会核实并采取停止处理、删除等措施。监护人可通过本页联系方式联系我们。

九、政策更新
我们可能随服务变化更新本政策，并在本页展示版本和生效日期。对处理目的、信息种类、提供对象或您的权利有实质影响的变化，将以显著方式告知；需要取得同意或单独同意的，将重新征求。您可以随时通过“我的—隐私政策”查阅当前政策。

十、联系我们
如您对信息处理、权利申请或本政策有疑问，请联系本页顶部列明的隐私事务联系人。请提供请求类型及必要的订单线索，不要通过公开留言发送完整地址、身份证件或支付凭证。

依据：[个人信息保护法](https://www.samr.gov.cn/wljys/gzzd/art/2023/art_3ef1e889c1e644d4b65b5f5c7f432386.html)、[电子商务法](https://www.gov.cn/xinwen/2018-08/31/content_5318220.htm)。

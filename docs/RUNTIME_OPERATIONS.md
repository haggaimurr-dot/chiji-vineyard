# 配置、媒体与运行任务（Mock）

使用 `VITE_USE_MOCK=true` 启动运营后台，以超级管理员登录，在「运营配置」打开「配置、媒体与运行任务」。该面板仅在演示模式显示，普通运营账号不能调用相关接口。

## 操作流程

1. 数据库迁移：模拟按顺序应用基础表和各模块迁移，保留应用时间，重复执行跳过已完成项目。不会访问真实 MySQL，新增任务记录也仅保存在浏览器。
2. 外部调度：启用外部调度并填写平台、HTTPS API 地址和媒体域名。允许缩容到零时，禁止保存未启用外部调度的配置。表格列出建议频率及调用动作；不会创建云端调度器或后台计时执行任务。
3. 媒体域名验收：模拟 HTTPS、图片类型、视频 Range、HEAD、缓存及微信真机播放检查；可模拟 Range 失败。修改媒体域名后自动清除旧验收。所有检查结果均为模拟，不能作为正式域名已上线的证据。
4. 任务执行记录：选择任务、手动或外部来源、是否模拟失败，生成包含执行ID、来源、操作者、起止时间、耗时、结果的记录。迁移未完成时阻止执行，外部调度未启用时阻止外部模拟。失败可重试，旧失败记录保留，新记录关联原执行ID。支持任务与状态过滤、每页10条分页。
5. 集中监控：检查待迁移、缩容调度缺失、媒体验收、任务失败或超过三个周期未执行、30天恢复演练缺失。页面每30秒刷新，刷新不覆盖尚未保存的配置。成功重试消除当前任务失败告警，历史失败次数仍保留。
6. 备份恢复演练：创建本模块配置、迁移状态和媒体验收的模拟快照，计算 SHA-256；选择备份恢复到隔离内存副本，再核对摘要。可模拟损坏并记录失败。演练不会替换当前配置，也不备份其他模块、真实订单或媒体二进制文件。

数据存储在浏览器 localStorage 的 `chiji_runtime_operations_demo_v1`；刷新和重新登录后保留，清理浏览器数据后删除。最多保留200条执行记录、20份备份和50条演练记录。没有真实耗时的同步模拟显示0ms，不伪造运行时间。没有真实数据库、外部调度和域名凭据时，不能认定生产操作已完成。

## 生产接入待办

生产仍按 `DEPLOYMENT.md` 执行真实迁移和调度配置。新面板不暴露到真实 API；`internal.publishArticles` 为拟接入的外部发布动作，当前后端仅有容器内定时器及请求补处理。生产接入需补该入口、持久化运行日志与受保护的监控接口，正式域名实际网络和真机验收，以及包含数据库和媒体文件的隔离恢复演练。

验证：`npm run test:runtime`，`npm run admin:typecheck`，`npm run admin:build`。

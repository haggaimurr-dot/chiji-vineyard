# 小程序个人数据管理

入口：「我的—账号与个人数据」；地址列表底部也可进入。

可自助删除全部保存地址，或清空购物车、商品与课堂收藏、提醒及通知、浏览搜索记录、学习进度、课堂问答与访问行为记录。两个范围分别确认，取消不执行；后端成功后才清理对应本地缓存。单独删除不改变订单、券包和活动预约，历史订单中的地址快照仍保留。

注销须无未完成订单、退款和售后，输入「注销账号」并再次确认。后端重新检查条件，事务内删除个人资料和使用数据、取消预约及候补、解除交易数据与微信身份的关联、删除所有小程序会话，并记录身份摘要作为注销标记。失败全部回滚。微信自动登录不能恢复已注销账号；用户须主动「重新注册」，旧数据、券包及历史订单不会恢复。

交易、退款、发票、售后凭证、评价及相关订单快照保留，改用不可登录的随机关联标识。解除身份关联不等同于凭证内容匿名化。本次不实施交易凭证及备份的自动到期删除；额外删除请求、合作申请及备份处理通过隐私联系方式受理。页面明确说明这些范围，发布后的隐私政策须由运营同步审核更新，更新默认草稿不会覆盖已发布配置。

## 部署与验证

已有数据库部署前执行 `backend/migrations/20261008_personal_data.sql`；新安装使用完整 `backend/schema.sql`。访问行为表需同时安装 `backend/migrations/20261008_commerce_analytics.sql`。MySQL 必须支持 `GET_LOCK` / `RELEASE_LOCK`，所有小程序请求及登录按微信身份串行执行，避免并发请求在删除后回写；数据库连接池须容纳锁连接和业务连接，竞争超时返回可重试提示。

`npm run mini:build`，`node tests/personal-data.cjs`，`node tests/flows.cjs`，`node tests/cross-end-updates.cjs`，`cd backend && go test ./...`。

覆盖删除范围、身份隔离、注销阻断、确认取消、重复点击、撤销会话、注销标记、事务失败回滚、删除失败保留本地缓存、禁止隐式重建和主动重新注册。数据库事务测试使用驱动模拟；正式发布仍需在部署用 MySQL 和微信开发者工具完成验收。

# 首页活动预约与个性化推荐

首页新增独立的「活动预约」与「为你推荐」模块，沿用现有页面配色、商品详情跳转和图片失败提示。

## 活动预约

后台「运营配置 → 首页运营位 → 活动专区」勾选「开放活动预约」并保存。新活动自动生成固定标识，已有活动首次开启预约时生成；编辑标题、日期或调整顺序不会改变标识。全新活动应通过「添加活动专区」创建，避免沿用旧活动的预约记录。

每位微信用户对同一活动保留一份预约，重复提交不会产生多条记录。未开始及进行中的活动均可预约，截止到活动结束日期的北京时间当天结束。活动关闭、结束或删除后不能新增预约，但已预约用户仍可取消；删除后的预约显示为「已下线的活动预约」。预约登记参与意向，不收取费用，不承诺席位，预约后提供小程序内提醒。

预约状态在进入首页及下拉刷新时重新读取，加载失败提供独立重试。取消失败保留原状态，提交响应丢失后回读服务端状态；并发请求以最新状态为准。

演示模式的预约保存在本机 `chiji_demo_activity_reservations`，不会进入正式数据库。正式模式通过已验证微信身份隔离记录。

## 活动预约成功通知

预约提交成功后显示确认提示，可直接查看通知；首页预约模块及「我的 → 活动通知」也提供入口。每次从未预约变为已预约时生成一条站内成功通知，保存预约时的标题、起止日期和预约时间（北京时间）。重复提交不重复生成，取消后历史保留，再次预约生成新通知。通知不代表当前仍处于预约状态，以活动专题页为准。

正式模式按微信用户隔离通知，预约和通知在同一数据库事务中写入；通知写入失败会回滚预约。支持未读数量、点击已读、20条分页、下拉刷新及失败重试。删除活动后通知仍保留，点击专题页提示活动已下线并可返回首页。旧预约不补造通知。演示模式使用本机 `chiji_demo_activity_notices`；预约成功通知仍为站内通知；微信开始提醒需在活动专题页单独订阅。

## 活动预约提醒与专题页

首页「活动预约提醒」展示已预约且未结束的活动，按开始日期排序，显示距开始天数、明天开始、今天开始或活动进行中。日期按北京时间计算，结束日期当天仍展示。进入首页及下拉刷新时更新；取消预约后移除提醒，活动删除后保留原有下线预约取消入口。预约状态读取失败时隐藏提醒，并在活动预约模块提供重试。

活动专区、预约卡片、提醒及成功通知均可进入独立的 `pages/activity/index` 专题页，展示封面、标题、简介、地点、日期、完整正文、预约状态和关联商品。专题页可预约、取消、分享给微信好友、下拉刷新与返回首页；返回首页重新读取预约状态。分享链接使用固定活动标识，接收者查看自己的预约状态。关联商品读取失败不影响活动正文和预约，进行中且商品可用时提供商品入口。

后台「活动管理」可填写可选的专题封面 HTTPS 地址及活动地点；封面域名需在微信后台配置为允许的图片域名。未填写封面或封面加载失败时仍展示完整文字内容。新增字段沿用首页配置、版本及回滚，无需修改配置表。

新活动沿用固定活动标识；未设置标识的历史活动兼容列表位置与标题校验，内容变更导致链接不匹配时提示返回首页重新选择。首页站内提醒直接使用已有预约记录；微信开始提醒按下文单独配置。

微信开始提醒的配置、部署及验收见 [ACTIVITY_WECHAT_PUSH.md](ACTIVITY_WECHAT_PUSH.md)。

## 个性化推荐

用户可选择「随心挑选」「家庭自享」「送礼分享」。推荐优先匹配明确偏好，其次考虑已收藏商品和收藏商品的同类商品；同分时按后台精选顺序及商品列表顺序排列。仅展示有库存且允许购买的商品，价格使用可购买规格最低价，最多展示三款；「换一换」轮换候选商品。

卡片展示推荐理由，点击进入商品详情。偏好及个性化开关保存在本机 `chiji_home_preferences`，刷新后保留。关闭个性化后展示当季推荐，不使用偏好或收藏参与排序。未收藏或未选择偏好时按后台精选顺序回退；暂无可买商品时展示空状态。当前推荐范围沿用 `product.list` 的返回范围。

## 上线与验证

已有数据库执行 `backend/schema.sql` 的 `activity_reservations` 建表语句；此次新增通知需先执行 `backend/migrations/20261007_activity_notices.sql`，再同步发布后端、小程序及后台。新数据库执行完整 `backend/schema.sql`。后台的活动标识与预约开关沿用现有首页配置、版本和回滚存储。活动内容回滚可能恢复对应标识原有的预约记录。

本地验证命令：

```text
npm run mini:build
npm run test:home-features
node tests/cross-end-updates.cjs
node tests/flows.cjs
npm run admin:build
cd backend
go test ./...
```

自动化覆盖预约与取消、重复提交、状态持久化、成功提示、通知快照与已读、分页与失败重试、用户隔离及事务回滚、封面失败、分享链接、活动结束及下线、网络失败、旧响应保护、推荐排序、过滤售罄和关闭个性化。正式 MySQL 与微信真机环境仍需部署后联调验收，包括好友打开分享、真实封面域名与跨设备通知读取。

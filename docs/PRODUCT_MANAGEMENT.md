# 商品与库存模块

## 操作

商品列表按名称、产地和规格搜索，可组合分类、发布状态和现货／预售条件，每页 20 或 50 款。查询在服务端分页，不受旧接口 100 款上限影响；当前页规格一次批量读取。搜索防抖，旧响应不能覆盖新的查询。失败保留页面并显示错误，支持刷新；图片延迟加载。批量库存调整只操作当前商品页的规格，一次最多 200 个，逐项勾选并填写原因。

编辑商品时记录打开页面时的库存。保存前后端锁定规格并校验；下单、取消、退款或其他管理员已改变库存时，整个商品保存回滚，草稿留在编辑框中。关闭后刷新再编辑。旧客户端未提供 `expectedStock` 时保存商品资料，保留数据库中已有规格的实时库存；新增规格可以设置初始库存。预占和已售数量始终由订单业务维护。

低库存告警沿用已发布、启用告警且可售库存小于等于阈值的规则，默认 10。可设置规格阈值、关闭告警或直接补货；补货后自动解除。草稿和停用规格不告警。库存流水记录调整前后可售、预占及已售数量，并与业务操作一同提交或回滚。仅有读取权限的账号不能调整库存或修改阈值。

### 批量导入

进入「批量导入」，下载模板并保存为 UTF-8 CSV，保留表头。每行一个规格；同一商品的分组、名称、副标题、分类、模式、发货日期、封面和产地必须一致。同一商品内规格名称不能重复。

分类填写 `family` 或 `gift`，模式填写 `spot` 或 `presale`。预售必须填写有效的 `YYYY-MM-DD` 发货日期。售价以元为单位，最多两位小数；库存为非负整数，限购为正整数。单文件最多 1MB、500 个规格，支持 CSV 引号、逗号及换行字段。

上传后查看逐行错误和商品／规格预览。有任何错误时不能提交。确认后整批创建草稿，不覆盖已有商品、规格、售价或库存。后端再次验证原始文件，所有商品、规格、库存流水及导入日志在同一事务里写入；任何写入失败整批回滚。导入后在商品列表筛选草稿，检查图片、售价、重量和销售资料后再上架。导入响应丢失时先查询草稿和操作日志，确认结果后再决定是否重新导入，避免手动重复创建。

### 批次管理

从商品行的「批次」进入该商品批次，或通过「批次管理」查看全部。新增时关联商品，登记批次号、果园／地块、采收日期、包装日期、有效期和备注。未采收可以留空；包装日期不能早于采收日期，有效期不能早于采收或包装日期。同一商品批次号唯一。

支持搜索、状态筛选、分页、编辑及归档。保存使用版本校验，多人同时修改时拒绝旧版本；商品归属不可更改。归档保留资料，不删除历史。

这里管理的是批次档案；可售、预占、已售库存仍按规格计数。登记或归档批次不增减库存、不自动按批次分配订单；商品详情现有的当前批次溯源资料保持独立，实发批次以包装标识为准。

## 发布与验证

旧数据库先执行 `backend/migrations/20261006_product_management.sql` 创建 `product_batches`，再同步发布后端和后台。新环境执行完整 `backend/schema.sql`。已有库存功能仍需要 `inventory_movements` 和 `inventory_alert_settings`。本次不修改小程序。

新增接口：`admin.product.search`、`admin.product.import`、`admin.batch.list`、`admin.batch.save`。查询需要 `product.read`，批次保存需要 `product.write`，导入和商品编辑同时需要 `product.write` 与 `inventory.write`。演示模式的数据在当前标签页会话内保存，与正式数据库隔离。

2026-10-06 本地验收使用临时 MySQL 8.4.6／InnoDB，运行真实后端业务函数及数据库事务，不使用数据库模拟驱动：

| 场景 | 结果 |
| --- | --- |
| 60 个并发请求争抢 17 件库存 | 17 次成功、43 次库存不足；可售 0、预占 17，无超卖 |
| 同一订单重复取消 12 次 | 只释放一次，流水一条 |
| 同一订单重复付款 12 次 | 只确认一次，流水一条 |
| 同一订单付款与取消竞态 | 只有一个终态生效，库存数量守恒 |
| 同一订单重复成功退款回调 12 次 | 未发货库存只回补一次，退款流水一条 |
| 20 个管理员同时按相同旧库存盘点 | 仅一个保存成功，预占与已售不变 |
| 批量盘点包含不存在的规格 | 已执行的前项回滚 |
| 商品编辑提交旧库存 | 整个保存回滚 |
| 导入第二款商品的流水写入失败 | 全部商品、规格和流水回滚 |
| 125 款商品，偏移 100 分页 | 正确返回第六页及当前页规格 |
| 批次编辑提交旧版本 | 拒绝覆盖 |

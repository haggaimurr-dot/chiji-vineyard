# 保存预览、跨端更新与账号密码重置验收

验收日期按北京时间记录。本次本地检查日期：2026-10-04 至 2026-10-05。

## 后台保存与预览

在「运营配置」的首页运营位、隐私政策中：

1. 修改标题，点击「预览当前编辑」。预览显示打开时的编辑快照及未保存标识，不调用保存接口。关闭预览后编辑内容仍保留。
2. 点击「保存并预览首页 / 隐私政策」。保存期间不可修改表单或重复提交；接口确认写入后重新读取配置及商品、文章，预览显示「已回读保存值」。
3. 保存失败保留编辑内容并显示错误；保存已确认、回读失败时显示「重试回读保存值」，不得展示保存成功预览。继续编辑后重试回读，新的编辑不能被回读值覆盖。
4. 在预览中核对轮播顺序与跳转目标、推荐内容顺序、活动及公告全文、日历月份、果园介绍和合作入口；无效目标和图片失败有提示。未到发布日期的公告不展示。
5. 隐私草稿显示「仅后台预览，用户不可见」；拟发布状态仍属于未保存编辑。缺少主体、联系方式或地址不能发布，完整正文可预览。
6. 演示后台配置、账号及凭据摘要保存在当前标签页的会话存储中，刷新后可继续预览；关闭会话后可以重新初始化。小程序演示数据独立，后台演示保存不会同步到演示小程序。

## 同一后端的正式跨端验收

### 前置条件

- 使用独立验收环境和验收账号；先备份待修改配置。
- 后台 `VITE_USE_MOCK=false`，`VITE_API_BASE_URL` 指向验收云托管服务；小程序 `demoMode=false`，确认 `cloudEnv`、`cloudService` 与后台为同一服务和数据库。
- 后端已部署本次版本，执行适用的数据库初始化或迁移；小程序修改 TypeScript 后执行 `npm run mini:build` 再由微信开发者工具编译。
- 记录环境、服务、后端版本和客户端版本，凭据和连接密码不进入截图或报告。

| 操作 | 小程序预期 | 证据 |

## 账号与密码重置

1. 超级管理员打开「添加账号」表单，填写用户名、角色、启用状态和两次密码。密码为 10–128 个 Unicode 字符，输入必须遮罩；短密码、过长密码、两次不一致、重名均不得创建。
2. 取消、关闭或按 Escape 返回列表；再次打开时密码为空。创建成功后列表回读，错误不丢失其他账号。
3. 启用、停用操作需确认；当前登录账号不能停用，必须保留至少一个启用的超级管理员。运营账号无账号管理和系统配置权限，直接调用接口同样拒绝。
4. 点击目标账号「重置密码」，输入并确认新密码；面板说明全部旧会话失效。密码、密码哈希或凭据指纹不得出现在账号列表、操作审计、成功消息中。
5. 预先在另一客户端登录该账号，重置后旧会话的下一次请求应被拒绝；旧密码登录失败，新密码成功。重置停用账号后仍停用，不能登录。
6. 重置当前账号时立即回到登录页，清空旧令牌与密码，使用新密码重新登录。网络或审计写入失败不得显示重置成功；事务回滚后旧密码及旧会话保持原状态。

后端接口：`admin.account.resetPassword`，请求为 `{ "accountId": "目标账号ID", "password": "新密码" }`。仅超级管理员可以调用。无需新增数据库字段；管理员令牌绑定当前密码凭据，升级前签发的旧版管理员令牌需要重新登录，小程序令牌不受该机制影响。

## 本地检查与正式验收边界

```powershell
npm run check
npm run test:operations
npm run test:flows
npm run test:refunds
npm run mini:build
```

在 `backend/` 执行 `go test ./...`、`go vet ./...` 和 `go build ./...`。

- `tests/admin-account-flows.cjs`：演示账号创建/重置、角色权限、旧会话失效、停用状态、刷新持久化及不保存明文密码。
- `tests/cross-end-updates.cjs`：后台演示保存经模拟云请求传输，运行实际小程序 TypeScript 页面逻辑，检查首页/政策更新、竞态、撤回和失效目标。
- `backend/cross_end_updates_test.go`：真实 HTTP 请求进入 `Server.api`，覆盖授权、配置保存、后台回读和用户端读取，数据库由内存 `database/sql` 驱动替代。
- `backend/account_test.go`：账号事务、重名、自停用、最后超级管理员、密码重置、会话失效和审计失败回滚。

上述检查不能替代真实 MySQL、云托管环境和微信真机联调。当前没有可用的正式连接配置，正式跨端验收仍需按上表执行并记录结果，不能标记为已通过。

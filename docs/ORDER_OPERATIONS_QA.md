# 订单批量操作验证

## 验证范围

| 用户操作或行为 | 功能检查 | 页面检查 |
| --- | --- | --- |
| 勾选当前页订单、取消勾选、切换分页与筛选 | 切换后清空旧选择，批量发货最多50笔 | 勾选数量与按钮状态一致 |
| 批量发货、失败项重试 | 每单独立结果，成功项锁定，相同运单重试不重复通知 | 表单可滚动，提交及关闭按钮可见 |
| 导出所选、导出筛选结果 | 全部匹配数据包含后续页；金额、中文、长编号、公式字符正确 | 下载后显示订单数量 |
| 获取电子面单 | 付款及退款限制；同单复用；生成后仍待发货 | 账号未配置及失败状态有说明 |
| 打印面单、确认交寄并发货 | 打印复用已保存图片；发货使用相同运单号 | 示例清楚标注不可交寄；打印窗口可打开 |
| 异常结果 | 网络不确定不重复创建；退款订单、重复运单被拒绝 | 错误显示，能够关闭或重试合适操作 |

自动检查覆盖接口状态、导出完整性、幂等和异常路径；页面检查使用后台演示模式。真实快递100账号、MySQL并发事务、打印机纸张和微信实单同步需按 [订单操作说明](ORDER_OPERATIONS.md) 验收。

## 本地验证结果（2026-10-05）

- `npm run check`：小程序及后台类型检查、后台正式构建通过。
- `npm run test:flows`：现有功能、订单搜索和新增订单操作流程通过；新增测试覆盖125笔订单跨页导出、超过10000笔限制、CSV公式及长号码保护、逐单失败、幂等重试、面单与发货一致性。
- `go test ./...`、`go vet ./...`：全部通过。测试使用模拟HTTP服务和事务状态驱动，覆盖快递100签名、明确拒绝、未知结果、图片校验、并发创建和保存图片后重复读取。
- Chromium 演示后台：下载全部、退款筛选及所选CSV，核对范围及BOM；混选退款订单不能进入批量发货；获取示例面单后保持待发货；100×180毫米打印设置生效且明确标注不可交寄；批量表单自动填入面单单号，发货成功后该行锁定且订单进入待收货；再次查看复用原面单且不再显示发货按钮。
- 弹窗：进入时获得焦点，Tab保持在弹窗内，加载期间不允许关闭，加载完成后Escape关闭并恢复触发按钮焦点。
- 桌面布局：1600、1280及1180像素宽度检查；主要批量操作与导出按钮完整可见，窄屏操作列固定；浏览器无页面异常。

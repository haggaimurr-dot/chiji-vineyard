# 合作线索：客户档案、商机金额、成交漏斗

在后台「合作线索」点击「客户档案 / 跟进」，查看原有客户、联系人、电话、渠道、地区与采购需求，补充客户邮箱、行业、地址及档案备注。商机金额以人民币元输入，允许 0–10 亿元和最多两位小数；0 表示尚未估值。接口和存储使用整数分。

保存沿用 `lead.write` 权限和版本冲突检测，档案与金额修改保留操作人、时间及不可变快照；旧线索自动显示空档案和零金额。CSV 导出包含档案与商机金额。客户档案内容也可搜索。

成交漏斗显示新线索、已联系、有意向、已成交、已关闭的当前数量及金额。按关键词、渠道、地区、负责人和提醒筛选全部匹配线索，不受列表分页或状态筛选影响；点击阶段可筛选列表。成交占比为已成交数量 / 全部匹配线索（含已关闭），并非历史阶段转化率。商机金额是估值，不是实际收款。

新增只读接口 `admin.lead.funnel`，使用 `lead.read` 权限。正式模式在数据库按筛选条件聚合；演示模式使用本地持久化数据。沿用 `partner_leads.payload` 和 `partner_lead_history.payload`，无需新增表；既有跟进历史表仍需按原部署说明创建。同步发布后台与后端。

验证：`npm run test:leads`（含 225 条跨页统计、金额校验、保存历史和刷新回读）、`node tests/lead-crm-ui.cjs`（需在 5187 端口启动后台演示模式）、后台构建及后端测试。

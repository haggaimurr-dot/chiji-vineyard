# 合作与个人中心资料

合作页和「我的」共用客服与主体信息组件，进入页面时重新读取。客服与隐私资料独立加载，失败可重试；过期请求不会覆盖新值。

小程序演示模式使用 `miniprogram/data/service.ts` 中的 mock 数据：虚构主体、虚构地址、`privacy@example.com` 示例邮箱和 `400-000-0000` 示例号码。页面明确标注演示，在线客服只提示，不进入真实会话，电话按钮不拨号。隐私正文沿用现有草稿，mock 不代表正式发布。后台演示配置与小程序演示数据独立。

后台「运营配置 → 首页运营位 → 合作与个人中心客服」维护开关、原生微信客服、电话、服务时间与合作回复时效。客服配置随首页保存，沿用配置版本、审计、回滚和保存后回读预览，不需要新增数据库表。旧配置没有客服字段时默认关闭。隐私政策表单填写主体、地址、隐私联系方式及正文，在正式发布后向用户展示。

正式接入时，替换 mock 主体及联系方式，在微信公众平台配置原生小程序客服接待人员，保存并发布真实隐私资料，再关闭演示模式。后台开关仅控制入口，不能代替微信平台的接待配置。正式客服会话和客服电话需真机验证。

验证：`node tests/service-info.cjs`、`npm run check`、`npm run mini:build`。后端客服校验可独立运行：在 `backend` 执行 `go test customer_service.go customer_service_test.go`。

# 迟记葡萄牙

本仓库包含微信小程序、Vue 运营后台、Go / MySQL 后端和独立微信小游戏的完整源码。第三人称小游戏原型已支持四个人物选择、亲手定植，以及雨前采收与交货两章；运行方式与实际实现范围见 [下地闯关原型说明](docs/VINEYARD_GAME_FIELD_IMPLEMENTATION.md)。

公开仓库不包含本机数据库、管理员密码、微信及支付密钥、开发工具私有配置和编译产物。请依据各目录的 .env.example 与 [部署手册](docs/DEPLOYMENT.md) 配置自己的环境；小游戏首次运行前先执行 npm run game:build。

独立葡萄园微信小游戏第一版已提供：四地块模拟种植、农事管理、采收分级、库存销售、设施和季末复盘；商城首页与个人页提供配置后的小游戏跳转。仓库根目录运行 npm run game:build、npm run game:preview 试玩；微信工程、真实 AppID 与正式后端配置见 [小游戏说明](minigame/README.md)，实现与验收见 [首版说明](docs/VINEYARD_GAME_IMPLEMENTATION.md)。当前默认本机演示，真实微信登录与发布需配置独立小游戏身份。

购物袋、优惠与配送模块新增用户券包与自动匹配最优券：兑换码入包、状态筛选、结算默认按实际抵扣选最优，支持手动选择及不使用。上线先执行 `backend/migrations/20261008_coupon_wallet.sql`，再发布后端与小程序。用法、匹配规则及当前后端全量编译阻塞见 [券包说明](docs/COUPON_WALLET.md)，专项验证：`npm run test:coupons`。

首页与活动模块新增预约成功站内通知及活动专题：预约成功弹窗、通知历史与未读状态、首页/个人中心入口；专题支持封面、地点和好友分享。重复预约不重复通知，取消后保留历史；正式环境先执行 `backend/migrations/20261007_activity_notices.sql`，再同步发布后端、小程序和后台。当前不发送微信订阅消息。说明见 [首页活动功能](docs/HOME_FEATURES.md)，验证：`npm run test:home-features`。


收藏与商品提醒新增自定义目标价格和提醒历史：按同一规格到价判断，支持修改/恢复默认条件；历史保留发送时快照及发送结果，取消提醒后仍可查看。已有数据库上线前执行 `backend/migrations/20261007_reminder_targets_history.sql`，详见 [商品提醒说明](docs/PRODUCT_REMINDERS.md)。
商城列表新增发货方式、库存状态和价格区间组合筛选，支持当前设备搜索历史（最近10条、逐项删除与确认清空）和按在售商品销量推荐的热门搜索。与分类、关键词、排序及服务端分页联动，正式与演示模式规则一致。无需新建表，需同步发布后端和小程序。说明见 [商城筛选与搜索](docs/SHOP_SEARCH.md)，验证：`npm run test:shop`。

后台「商品与库存」支持服务端搜索与 20／50 款分页、CSV 批量导入预览及整批创建草稿、独立批次档案与归档；商品编辑增加库存冲突校验。真实 MySQL 8.4.6 已验证并发下单、重复取消／付款／退款及并发盘点。既有低库存告警与库存流水回归通过。上线先执行 `backend/migrations/20261006_product_management.sql`，操作与验收见 [商品与库存模块](docs/PRODUCT_MANAGEMENT.md)。

电子面单新增后台网点/月结账号与寄件资料配置、8 家承运商独立启停和协议价运费比较。运营配置填写各家账号、V2 模板及省份价目表，订单中按毛重查看排序后的预估费用并选择承运商取号打印。凭据保存后不回显、留空保留，版本冲突拒绝旧配置覆盖。本次按要求使用 mock 数据完成配置、比较与重复打印流程验证，演示面单不可交寄。说明见 [电子面单操作手册](docs/ORDER_OPERATIONS.md)，专项验证：`npm run test:waybills`；无需新增配置表。

经营概览新增北京时间日期筛选、退款后净收入、每日销售趋势、期间复购率与订单转化漏斗。按所选期间下单的订单统计，净收入扣除截至当前的成功退款；待办数量不受日期筛选影响。正式后端和后台需同步发布，无需新建表。统计口径见 [经营概览说明](docs/DASHBOARD_ANALYTICS.md)，验证：`npm run test:dashboard`。

后台「合作线索」新增客户档案、商机金额和成交漏斗，支持档案搜索、修改快照、CSV 导出及按筛选条件统计全部线索。用法见 [合作线索 CRM](docs/LEAD_CRM.md)。

订单与优惠结算新增幂等下单、丢响应恢复及区域配送规则（省／市／区县、按件续费、包邮门槛、地区附加费、暂停配送日期）。上线需先新增 `order_idempotency` 表，并协调发布带幂等键的新小程序与后端。用法与验证见 [订单结算说明](docs/CHECKOUT_SETTLEMENT.md)，专项验证：`npm run test:checkout`。

首页新增活动预约与个性化推荐。后台在活动专区开启预约后，用户可预约、取消并在刷新后查看状态；推荐区根据购买偏好和收藏排序，支持换一换及关闭个性化。正式上线需新增 `activity_reservations` 表并同步发布后端、小程序；使用说明见 [首页新增功能](docs/HOME_FEATURES.md)，专项验证：`npm run test:home-features`。

种植课堂新增内容搜索、课堂收藏和学习记录，支持组合筛选、分页、列表及详情收藏、个人中心快捷入口。正式模式按用户保存，演示模式本地保存；上线需新增 `article_favorites` 表及阅读查询索引，见 [课堂学习功能说明](docs/CLASSROOM_LEARNING.md)。

商城新增浏览记录和商品对比，商城与「我的」均提供入口。浏览记录在成功打开详情后自动保存最近 50 款，重复浏览更新顺序，支持单项删除和确认清空；商城卡片、详情和浏览记录可加入或移出对比，最多 4 款。对比页横向查看最新价格、品种、产地、各规格价格与重量、库存、发货方式、销量、保存与净重说明。两类记录仅保存在当前设备，演示与正式模式隔离；进入页面重新读取商品详情，下架或加载失败的项目保留名称并提供移除、刷新与重试。无需新建数据库表。运行 `npm run test:product-memory` 和 `npm run test:shop` 验证，发布小程序前运行 `npm run mini:build`。

首页 mock 轮播与后台商品预览已替换为本地葡萄示意图，首页运营位支持直接上传轮播图片；小程序首页提供图片失败提示与空内容状态。跨端保存、素材替换和刷新流程已通过模拟传输验证，浏览器上传 / 回读检查运行 `npm run test:home-ui`；结果与正式验收边界见 [首页验收报告](docs/HOME_TEST_REPORT.md)。

后台新增「运营配置 → 配置版本与回滚」及「操作日志」。运费、优惠券、首页运营位和隐私政策每次保存均留存完整快照，首次变更前保留原配置；回滚需填写原因，会生成新版本并记录操作人，配置已被其他人更新时拒绝旧页面的回滚。快照详情可输入同一配置的任意两个版本号，查看新增、删除、修改字段及原值/目标值（数组按位置对比）。超级管理员可按操作类型、用户名、目标和北京时间日期筛选日志，分页查看详情；「导出日志 CSV」导出已查询条件下的全部记录，不受当前页影响，最多 10000 条，超过时需缩小筛选范围。CSV 包含日志标识、操作人、操作类型、目标、北京时间和脱敏详情，并记录导出操作。演示配置、历史和日志在当前标签页会话内保存，刷新后保留；正式上线先执行 `backend/schema.sql` 中新增的 `config_versions` 建表语句。功能测试：`npm run test:config-history`。

微信原生小程序 + 腾讯云开发云托管（Go 容器）+ MySQL + Vue 3 运营后台。仓库仍保留界面演示模式，便于尚未开通商户支付时预览；演示数据不会进入生产数据库。

## 目录

- `miniprogram/`：原生微信小程序，正式模式使用 `wx.cloud.callContainer`。
- `backend/`：Go HTTP 服务、Dockerfile、MySQL 建表脚本。处理商品、购物车、订单、支付、发货、退款、课堂、合作和后台接口。
- `admin/`：PC 运营后台，正式模式通过云托管公网 HTTPS 地址访问同一 Go 服务。
- `docs/`：部署和验收说明。

## 本地预览

先执行 `npm install`、`npm run mini:build`，再用微信开发者工具导入仓库根目录，即可预览小程序的演示数据；`miniprogram/app.ts` 默认 `demoMode: true`。PC 后台运行 `npm install`、`npm run admin:dev`，后台演示模式单独由 `admin/.env.local` 中的 `VITE_USE_MOCK=true` 控制。

## 正式接入

收藏与提醒模块支持到货订阅消息及降价提醒。商品详情按当前选中规格记录降价关注价，「我的 → 降价提醒」显示关注价、现价、降幅；收藏列表可进入详情设置。微信到货、降价消息均需用户主动授权，成功发送一次后不重复发送；演示模式仅显示站内状态。新增降价功能需执行 `price_drop_notifications` 建表语句，配置 `WECHAT_PRICE_DROP_TEMPLATE_ID` / `WECHAT_PRICE_DROP_TEMPLATE_FIELDS`，并调度 `internal.priceDropNotices`。详见[部署手册](docs/DEPLOYMENT.md)，验证使用 `npm run test:price-drop`。

1. 创建开发、验收、生产三个云开发环境，每个环境配置独立 MySQL 和云托管服务。
2. 在数据库执行 `backend/schema.sql`，按 [部署手册](docs/DEPLOYMENT.md) 配置服务密钥、域名和微信支付。
3. 将 `miniprogram/app.ts` 的 `demoMode` 改为 `false`，填写 `cloudEnv` 和 `cloudService`；在 `project.config.json` 填写真实小程序 AppID。
4. 部署 PC 后台时将 `VITE_USE_MOCK=false`，并填写 `VITE_API_BASE_URL=https://你的云托管域名/api`。
5. 用一次性口令初始化超级管理员，再通过后台录入真实商品、果园照片和教学内容。

本地静态检查：`npm run check`；Go 编译：在 `backend/` 执行 `go build ./...`。未配置真实商户密钥和云环境前，支付、发货同步与退款只能在演示模式预览，不能视为已完成线上验收。

已提供后台首页运营位配置、带并发校验的批量库存调整、快递100物流轨迹查询与完整隐私政策页面。功能配置及上线条件见 [部署手册](docs/DEPLOYMENT.md)，政策正文见 [隐私政策](docs/PRIVACY_POLICY.md)。功能流程检查：`npm run test:flows`；后端测试：在 `backend/` 执行 `go test ./...`。

小程序修改 TypeScript 后需重新运行 `npm run mini:build` 生成相邻 JavaScript 文件；部分开发者工具版本未自动执行 TypeScript 插件，仅类型检查不能保证模拟器可启动。

购物袋提供「管理」模式，勾选商品后支持批量删除（需确认）和移入收藏，全选也通过新增的 `cart.batch` 接口执行。正式模式在同一事务内保存收藏和删除选中的规格，同一商品多个规格只收藏一次，写入失败整批回滚；操作期间锁定按钮，失败后刷新并支持重试。演示模式同步支持批量接口，无需新增数据库表。参数及重试语义见 [购物袋批量接口](docs/CART_BATCH.md)。

首页提供活动专区、公告和上市日历。在后台「首页运营位」中添加、排序或删除对应内容，保存后小程序再次进入首页生效。活动按北京时间标记状态，进行中的活动可跳转关联商品；公告从发布日期起展示并可查看全文；上市日历按月份筛选预计产期，支持跨年。正式模式未配置时显示空状态，演示模式使用标有「示例」的独立数据；这些模块沿用首页配置存储，无需修改数据库表结构。

商城支持按品种、产地和规格搜索，并与商品分类联动；提供加载、空结果、异常重试和图片加载失败提示。售罄商品仍可查看详情，售罄规格不可购买，数量受库存和每单限购约束。详情页提供签收保存、问题举证、未发货退款说明与客服入口。`miniprogram/assets/products/` 中的三款图片由 imagegen 生成，仅用于演示，页面标注「商品示意图」；正式上线请通过后台上传真实商品图片，并在微信后台配置客服接待。
商城新增综合排序、价格升降序和销量降序，排序与搜索、分类联动。价格按最低规格价排序，无规格商品排在末尾；销量为所有在售规格的已付款净销量。商品卡片及详情支持收藏和取消收藏，售罄商品可设置到货提醒；「我的」提供收藏列表与到货提醒列表，进入时刷新库存，已补货商品显示「已到货」，个人页显示已到货数量。正式模式按微信用户保存，演示模式仅在本地保存。商品详情与到货提醒列表支持主动订阅一次微信到货消息，用户同意授权后由受信任定时任务检查可售库存并发送；拒绝授权不影响站内提醒。成功不重复发送，网络结果不确定时保留待核实状态。已有数据库需执行 `backend/schema.sql` 中的 `product_attention` 和 `restock_notifications` 建表语句，并配置微信模板与调度器，详见 [部署手册](docs/DEPLOYMENT.md)。

结算页新增优惠券兑换码与期望配送日期。后台「运营配置 → 优惠券」设置编码、商品金额门槛、抵扣额、北京时间有效期与启用状态；每人每码限用一次，待付款订单占用，未支付订单取消或关闭后释放，退款不返券。按优惠前商品金额判断包邮，券不抵运费，商品应付至少保留1分。演示模式使用 DEMO10（商品满99元减10元），与后台演示配置独立。配送可选北京时间两天后至30天内，也可尽快配送；预售不早于预计发货日期，期望日期不保证送达。

已付款且无进行中退款的订单支持申请电子普通发票（个人/企业抬头、企业税号、邮箱），每单一份，退回后可重新申请。后台订单列表展示申请资料和金额，运营人员人工开票后填写发票号码、上传 PDF（最大3MB），后台自动通过 SMTP 将 PDF 附件发送至申请邮箱；也可填写原因退回。后台支持下载发票、查看邮件发送状态、失败重试及不确定结果核实；小程序支持查看电子发票和发送进度。SMTP 接受邮件不代表已送达用户收件箱。未接入税务自动开票服务。需配置 SMTP_HOST、SMTP_PORT、SMTP_TLS_MODE（465/tls 或 587/starttls）、SMTP_USERNAME、SMTP_PASSWORD（邮箱授权码）和 SMTP_FROM，均仅在服务端配置。未配置邮件服务时，已开票文件仍保存，邮件标记失败，配置后可重试。已有数据库须额外执行 invoice_files 建表语句；文件私有存储，只允许申请用户和登录运营人员读取。发送结果不确定或发送中断超过一分钟时先核查邮件服务记录，登记已发送或未发送后才可重试，避免重复邮件。演示后台只模拟发送。已有数据库需执行 `backend/schema.sql` 末尾的优惠券空配置初始化与 `invoice_requests` 建表语句；申请状态独立存储，不受支付/发货快照更新影响。

售后支持举证图片、部分金额退款及已发货/已收货售后。在订单详情进入「申请退款 / 售后」，填写金额并上传最多6张图片；后台可查看私有举证并按申请金额审核。部分退款后显示累计已退金额，剩余金额可再次申请。已有数据库需执行 `backend/schema.sql` 中新增的 `refund_evidence` 建表语句。图片单张压缩至512KB以内，正式支付退款仍需在真实商户环境验收。

订单列表与详情新增「再次购买」，重新读取原规格的当前价格、库存及每单限购，售罄/下架规格跳过，数量变化需用户确认后进入结算。结算保留本次选择数量，不复用旧优惠券和配送日期。订单搜索支持订单号、商品名称和规格，多关键词与状态筛选联动，由服务端先搜索再分页，演示模式行为一致；后台也提供搜索和分页。

「我的—发货通知」显示站内发货通知及未读数量，查看订单详情后标记已读；同一订单仅生成一次。订单详情可主动订阅一次微信发货提醒，后台记录推送结果，明确失败可重试，网络结果不确定时保留待核实状态以避免重复发送。演示模式支持模拟订阅与模拟发货，不发送微信消息。正式上线需创建 `shipping_notifications` 表、配置微信订阅模板及字段映射并完成真机验收，详见 [部署手册](docs/DEPLOYMENT.md)。

退款 / 售后页面展示每次申请的审核进度、金额、时间与拒绝原因；后台可查询微信退款结果并按原单号重试待确认提交。正式退款需核对用户到账、商户退款单与库存，步骤和记录模板见 [正式退款验收](docs/REFUND_ACCEPTANCE.md)。

后台「合作线索」支持多关键词搜索客户、联系人、手机、需求及历史备注，组合状态、渠道和地区筛选后分页。跟进备注每次追加保存，历史展示操作人、时间和状态变化；旧备注保留为原时间未知的历史记录，仅调整状态不清空最近备注。CSV 导出全部筛选结果及完整跟进记录，演示跟进在浏览器本地保存，刷新后仍可查看。正式更新带版本校验；现有数据库需执行 `backend/schema.sql` 中 `partner_lead_history` 建表语句以保存不可变操作历史。验证命令：`npm run test:leads`。

商品评价支持最多6张晒图、一次追加评价（可附图）、后台评价审核及商家回复。首次评价须确认收货，每条评价可追评和回复各一次，评分保留首次值；新评价及追评审核通过后公开匿名展示，买家可查看审核状态及驳回原因。后台新增「商品评价」入口。已有数据库需执行 `backend/schema.sql` 中的 `review_details` 建表语句，并配置 HTTPS `PUBLIC_BASE_URL` 及小程序图片域名。运行 `npm run test:reviews` 验证，使用说明见 [商品评价功能](docs/PRODUCT_REVIEWS.md)。


后台「商品与库存」新增「库存流水」及「低库存告警」。流水记录商品保存、库存调整、下单预占、付款确认、订单取消/超时释放及退款完成的可售/预占/已售数量变化，支持规格、类型、关联单号及北京时间日期筛选和分页，保留商品与规格名称快照；无数量变化的操作不生成流水。业务更新与流水写入同一事务，记录失败整笔回滚。已上架且启用告警的规格在可售库存小于或等于阈值时出现站内告警，默认阈值 10，可按规格设置阈值或关闭；补货后自动解除，草稿及停用规格不告警。演示数据、流水和阈值在当前标签页会话内保存，刷新后保留。正式上线须先执行 `backend/schema.sql` 中新增的 `inventory_movements`、`inventory_alert_settings` 建表语句，再发布后端；流水从启用后开始记录，不补造历史，也不记录绕过服务直接修改数据库的操作。功能验证：`npm run test:inventory`；后端：`go test ./...`。

微信支付自动对账、异常告警及上线说明见 [WECHAT_PAYMENT_OPERATIONS.md](docs/WECHAT_PAYMENT_OPERATIONS.md)。

批次管理支持关联外部溯源平台、平台编码与 HTTPS 查询链接，并预览、下载内部溯源码和外部平台链接二维码。小程序公开查询展示平台资料并支持复制链接。使用及接入范围见 [批次外部溯源与二维码](docs/BATCH_TRACEABILITY.md)；验证：`npm run test:batches`。
